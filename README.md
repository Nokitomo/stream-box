# Vega Web Clone (Blueprint V1)

Static-first web clone for AU + SU with minimal backend runtime.

## Stack

- Frontend: Vanilla TypeScript SPA (hash router)
- Static data: `data/app/*` JSON generated by offline scrapers/build pipeline
- Runtime backend: Vercel Functions only for stream resolve/proxy (+ optional content fallback endpoints)
- User cloud sync: Supabase (optional login, guest-first)

## Main commands

```bash
npm install
npm run scrape:all
npm run test:data
npm run typecheck
npm run build
npm run dev
```

## Data pipeline outputs

- `data/app/catalog-index.json`
- `data/app/catalog-details/chunk-*.json`
- `data/app/search-index.json`
- `data/app/episodes-index.json`
- `data/app/episodes-chunks/chunk-*.json`
- `data/app/manifest.json`

## Runtime APIs

- `GET /api/player/streams?provider&link`
- `GET /api/player/proxy?url&headers`
- `GET /api/player/episodes?provider&seasonLink`

Optional static fallback/debug:

- `GET /api/content/meta?contentId`
- `GET /api/content/episodes?contentId&seasonKey`

## Supabase

1. Set:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
2. Apply SQL schema/RLS in `supabase/schema.sql`

Tables:

- `profiles`
- `user_watchlist`
- `user_history`
- `user_progress`
- `user_settings`

RLS owner policy is strict (`auth.uid() = user_id` / `id`).

## Daily refresh

GitHub Action `/.github/workflows/daily-catalog-refresh.yml` runs once/day and can be triggered manually.
