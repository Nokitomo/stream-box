# Design System Theme

## Overview
This document outlines the core visual theme of our design system, covering color, typography, and foundational spatial properties. The theme is designed to be cohesive and adaptable across various applications and platforms.

## Color Palette

### Color Mode
The current theme is set to **Dark Mode**, providing a darker interface experience that can reduce eye strain in low-light conditions.

### Primary Colors
The core of our brand identity is defined by a distinct palette.
-   **Primary Color:** `#E50914` - This vibrant red serves as the brand's most distinctive color, suitable for prominent interactive elements, calls to action, and key branding.
-   **Secondary Color:** `#2F2F2F` - A supporting dark gray for less prominent UI elements, such as secondary buttons, chips, and dividers.
-   **Neutral Color:** `#000000` - A deep black serving as the base for backgrounds, surfaces, and non-chromatic elements, especially suitable for dark mode.

### Named Colors
The theme utilizes specific hex values for various UI roles:
-   `primary`: `#E50914`
-   `secondary`: `#2F2F2F`
-   `tertiary`: `#E50914`
-   `neutral`: `#000000`

## Typography

Our typographic system uses the **Inter** typeface across all key text elements to ensure consistency and readability.

### Headline Font
The `headline_font` is set to **Inter**, chosen for its modern and highly legible characteristics, ideal for clear and impactful headlines.

### Body Font
The `body_font` is set to **Inter**, ensuring optimal readability for longer passages of text and general UI content.

### Label Font
The `label_font` is set to **Inter**, providing clear and consistent labeling for interactive elements and form fields.

## Shape and Spacing

### Roundedness
UI elements feature a **subtle roundedness (1)**, offering a touch of softness while maintaining a clean and modern aesthetic. This provides a balance between sharp angles and fully rounded corners.

### Spacing
The `spacing` is set to **Normal (2)**, providing a balanced and comfortable level of whitespace within and between UI elements. This ensures adequate visual separation without making interfaces feel overly dense or excessively sparse.
